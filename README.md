# Data Science & AI Lab Portfolio

Welcome to my personal Data Science sandbox! This repository is dedicated to continuous learning, experimentation, and project development in **Machine Learning**, **Data Mining**, and **Data Analytics**.

Here, I explore algorithms and insights by working with two types of data:
1. **Public Datasets:** Real-world data from platforms like Kaggle, UCI, or open-source APIs.
2. **Synthetic/Code-Generated Data:** Custom datasets created via Python (NumPy/Pandas) to simulate specific business logic and test model robustness.

## 🛠️ Tech Stack & Tools
* **Languages:** Python (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn)
* **Environments:** Google Colab, Jupyter Notebooks, GitHub
* **Key Areas:** Predictive Modeling, Feature Engineering, EDA, Data Generation

## 📁 Repository Structure

* **`01-machine-learning/`**: Predictive models, regression, classification, and model evaluation.
* **`02-data-mining/`**: Pattern discovery, clustering, and data extraction techniques.
* **`03-data-analytics/`**: Exploratory Data Analysis (EDA), data cleaning, and statistical visualization.
